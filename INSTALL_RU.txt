PPG Translate 2.3.0
===================

People Playground на 11 языках: English, Русский, Español, Português (Brasil), Deutsch, Français, Polski, Türkçe, 日本語, 한국어, 简体中文.

Это плагин для BepInEx 5, а не мод из меню игры, поэтому безопасный режим ему не мешает. Mod Enabler и RE_PPG для него не нужны.

Плагин не ходит в интернет, ничего не скачивает, не пишет файлы вне своей папки и не трогает файлы игры и сохранения. Исходники лежат в BepInEx/plugins/PPG_Translate/source.


Какой архив брать
-----------------
PPG_Translate_2.3.0_x64.zip - почти для всех: Steam, большинство версий не из Steam, Mac через CrossOver.
PPG_Translate_2.3.0_x86.zip - только для 32-битной игры.

Проверить просто: если в папке игры лежит UnityCrashHandler64.exe, нужен x64, если UnityCrashHandler32.exe, то x86. Перепутаете архив - игра запустится на английском, больше ничего не случится.

Нужна игра 1.24.5 или новее. Перевод сделан под 1.28.


Windows (Steam и не Steam одинаково)
------------------------------------
1. Закройте игру.
2. Если стоял старый русификатор из Мастерской, удалите папку Mods/2811789670 и папку %APPDATA%\01STUDIO (вставьте %APPDATA% в адресную строку проводника).
3. Откройте папку игры. В Steam: правый клик по игре -> Управление -> Просмотреть локальные файлы. В других версиях это папка, где лежит People Playground.exe.
4. Скопируйте туда всё содержимое архива, рядом с People Playground.exe.
5. Запустите игру. При первом запуске сам откроется список языков, выберите свой.


Mac (CrossOver)
---------------
1-2. Как на Windows. Папка 01STUDIO в бутылке лежит в drive_c/users/crossover/AppData/Roaming/01STUDIO.
3. CrossOver -> бутылка -> «Открыть диск C:» -> Program Files (x86)/Steam/steamapps/common/People Playground.
4. Скопируйте туда всё содержимое архива. Файл .doorstop_version Finder прячет, это нормально.
5. CrossOver -> бутылка -> «Настройка Wine» -> вкладка «Библиотеки» -> впишите winhttp -> «Добавить». У winhttp должно стоять native, builtin («сторонняя, затем встроенная»). «Применить» -> OK.
   Без пятого шага под Wine ничего не запустится.


Linux и Steam Deck (Proton)
---------------------------
Всё как на Windows, плюс в Steam: Свойства игры -> Параметры запуска:
WINEDLLOVERRIDES="winhttp=n,b" %command%


Как сменить язык
----------------
Главное меню -> кнопка «язык» -> выберите язык. Текст меняется сразу, перезапуск не нужен.
Такая же кнопка есть в меню паузы.
Кнопка «поддержать автора» в главном меню открывает в браузере страницы для доната на Boosty и lava.top.


Как понять, что всё работает
----------------------------
В главном меню появилась кнопка «язык», а в папке игры есть BepInEx/LogOutput.log со строками «PPG Translate», «Language: ...» и «Hook: TMP_Text.text».
Если лога нет, BepInEx не запустился. Обычно это значит, что файлы скопированы не в ту папку, а на Mac и Linux ещё и пропущен шаг с winhttp.


Обновление с PPG Russian
------------------------
1. Если вы правили translations/50_my.txt, сохраните его копию.
2. Удалите папку BepInEx/plugins/PPG_Russian целиком.
3. Скопируйте содержимое нового архива в папку игры с заменой. Свои правки перенесите в BepInEx/plugins/PPG_Translate/translations/ru/50_my.txt.
Настройки сохранятся, игра останется на русском.


Если что-то осталось на английском
----------------------------------
Плагин записывает такие строки в BepInEx/plugins/PPG_Translate/untranslated_<язык>.txt, например untranslated_ru.txt.
Свой перевод добавляется в translations/<язык>/50_my.txt по строке на фразу:
    English<TAB>Русский
Между ними именно табуляция, не пробелы. Файл сохраняйте в UTF-8. Числа можно заменять шаблоном:
    {0} bruises<TAB>Синяки: {0}
Изменения подхватываются при следующем запуске игры.
Нашли кривой перевод - напишите в Issues на GitHub, поправим для всех.


Антивирус ругается на winhttp.dll
---------------------------------
Это загрузчик BepInEx (Doorstop). Он подкладывается вместо системной библиотеки, чтобы запустить BepInEx вместе с игрой, и некоторые антивирусы реагируют на сам этот приём. Файл взят из официального релиза BepInEx 5.4.23.5 без изменений, его SHA-256 есть в SHA256SUMS.txt.


Настройки
---------
Файл BepInEx/config/ppgrussian.cfg появится после первого запуска. Имя осталось от PPG Russian специально, чтобы при обновлении настройки не терялись.
  Language = ru                 код языка: en, ru, es, pt-BR, de, ja, fr, pl, ko, tr, zh-Hans
  Enabled = true/false          включить или выключить перевод без удаления
  TranslateWorldText = true     переводить надписи на предметах и картах. Текст, который пишет игрок, не переводится никогда
  SweepIntervalSeconds = 2      как часто проверять экран на пропущенный текст, 0 - не проверять
  DumpUntranslated = true       вести untranslated_<язык>.txt


Удаление
--------
Удалите из папки игры winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt и папку BepInEx.
Если у вас есть другие моды на BepInEx (например RE_PPG), удалите только BepInEx/plugins/PPG_Translate.


Другие моды
-----------
RE_PPG ставит тот же BepInEx 5.4.23.5, так что они работают вместе.
Если в папке игры уже есть BepInEx другой версии (так бывает в сборках-репаках), не копируйте BepInEx из архива поверх. Перенесите только папку BepInEx/plugins/PPG_Translate.
